> **Plataforma completa de comercio electrónico desarrollada en Python y Django.**

## ✨ Funcionalidades
- Catálogo de productos completo con categorización.
- Carrito de compras persistente.
- Sistema de checkout y procesamiento de órdenes.
- Panel de administración integrado para gestión de inventario.
- Configuración lista para despliegue productivo (incluye `Procfile` y `vercel.json`).

## 🚀 Despliegue Local
1. `pip install -r requirements.txt`
2. `python manage.py migrate`
3. `python manage.py createsuperuser`
4. `python manage.py runserver`
